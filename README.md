🌍 TrueTraveller – Travel & Tourism Website

TrueTraveller is a modern, responsive travel web application built with React + Vite. It helps users explore destinations, travel guides, packages, and easily submit booking or contact requests with smooth navigation and form validation.

⸻

🚀 Live Demo

👉 https://nirmalkumar-1.github.io/TrueTraveller-web/

⸻

🛠️ Tech Stack
	•	React (Vite)
	•	React Router DOM
	•	Bootstrap 5
	•	JavaScript (ES6+)
	•	HTML5 & CSS3
	•	GitHub Pages (Deployment)

⸻

✨ Features
	•	🏠 Home page with travel highlights
	•	🌍 Destinations & gallery pages
	•	📘 Travel guides & packages
	•	📬 Newsletter subscription with success page
	•	📞 Contact form with redirect on submit
	•	❌ Custom 404 (Not Found) page
	•	📱 Fully responsive design
	•	🚀 Deployed on GitHub Pages

📂 Project Structure
  src/
  ├── components/
  │   ├── Home/
  │   ├── AboutUs/
  │   ├── Destinations/
  │   ├── TravelGuides/
  │   ├── TravelPackages/
  │   ├── Contact/
  │   ├── Footer/
  │   └── NotFound/
  ├── Layout.jsx
  ├── main.jsx
  └── index.css

🧭 Routing
  This project uses React Router (createBrowserRouter) with:
  	•	Clean URLs
  	•	GitHub Pages support using basename
  	•	Custom NotFound page for invalid routes
